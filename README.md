MSc student at **Gdańsk University of Technology**, working where computational chemistry meets bioinformatics.

I work on:
- cheminformatics and QSAR/QSPR modelling
- omics and chemometric data analysis
- small automation tools that save time

**Toolbox:**
- **Languages:** Python (pandas, NumPy, SciPy, scikit-learn, RDKit, matplotlib), SAS, MATLAB, SQL / PostgreSQL
- **Chemistry and data tools:** Orange Data Mining, PaDEL-Descriptor, MOPAC, CCDC Mercury, CrystalExplorer, PubChem / NCBI tools
